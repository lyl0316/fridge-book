# Fridge Book · Home Screen icon

A tiny page that gives Fridge Book (a Claude artifact) its own Home Screen icon in Safari.

1. Open `https://lyl0316.github.io/fridge-book/#<artifact-id>` in Safari.
2. Share → Add to Home Screen, switch off **Open as Web App**, then Add.

The fridge icon then opens `https://claude.ai/artifact/<artifact-id>` in Safari.
The artifact id stays after the `#`, so it is never sent to this site and isn't stored here.
